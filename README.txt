COPAPRO MANAGER
===============
Prototipo web responsive inspirado en un manager de fútbol.

Funciona en PC, Android, iPhone/iPad y navegadores modernos.
Para probarlo: abre index.html.
Para instalarlo como app (PWA), súbelo a un hosting con HTTPS y abre la web desde el navegador.

Incluye:
- Panel de club
- Plantilla
- Mercado de fichajes con presupuesto
- Liga/Copa/Europa
- Estadio y cantera
- Simulación de partidos
- Diseño responsive y barra móvil
